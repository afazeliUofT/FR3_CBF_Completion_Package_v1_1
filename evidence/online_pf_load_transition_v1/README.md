# Online moving-average PF and load-transition milestone

The validated one-seed milestone recomputes local RZF for deterministic user arrivals/departures, updates moving-average PF weights online, preserves the robust delayed safety certificate under 1 dB and 3 dB upper-coupling smoke margins, and safely handles two dropped commands.

The result is not a paper result. Uncertainty calibration and the multi-seed/multi-pass campaign remain open.
