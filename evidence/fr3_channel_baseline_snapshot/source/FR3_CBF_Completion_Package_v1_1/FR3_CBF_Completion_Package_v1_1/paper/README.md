# Paper workspace

`FR3_CBF_JSAC_TWC_draft_skeleton.tex` is a clean two-column manuscript skeleton. It deliberately contains `RESULT REQUIRED` markers rather than invented numbers.

Populate it only after:

1. the real S1 gate and decision exist;
2. E1, E2, and E3 real/model-validated audits exist;
3. uncertainty coverage and runtime evidence exist;
4. the readiness checker reports no missing required evidence.

Use the canonical definitions and theorem assumptions in `docs/FR3_CBF_System_Model.pdf`. Do not copy the tutorial prose into the paper.

The skeleton uses `references.bib`. A standard TeX installation with BibTeX is required to compile citations. The distributed package does not treat this unpopulated skeleton as a final paper.
