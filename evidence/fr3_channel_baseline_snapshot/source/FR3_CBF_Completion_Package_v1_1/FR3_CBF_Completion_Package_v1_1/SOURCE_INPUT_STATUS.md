# Source Input Status

The package includes the user-supplied official Recommendation archive:

- `source_documents/R-REC-P.530-19-202509.zip`

That archive contains the Recommendation PDF. The P.530 digital integral products are a separate official ITU components download and are not fabricated or embedded here. `scripts/02_download_p530_products.py` obtains or validates those components.

This package consolidates the audited technical state of the project into one canonical working directory. Earlier working reports remain useful history, but the system model, tutorial, YAML, roadmap, and code in this package should be used for future execution.
