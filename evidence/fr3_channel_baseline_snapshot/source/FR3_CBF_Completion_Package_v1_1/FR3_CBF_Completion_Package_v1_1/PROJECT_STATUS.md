# Project Status

## Status in one sentence

The project has a strong, coherent, standards-aware method and a paper-ready mathematical skeleton, but it still needs real S1 evidence, real E1-E3 simulations, calibrated uncertainty coverage, and runtime measurements before submission.

- Research question and novelty boundary.
- Slot timing convention.
- Beam-space incumbent-interference model.
- Physical-parameter robust uncertainty set.
- Rate-limited RRM model.
- Exact per-prefix exceedance budget.
- EMA reserve-margin barrier.
- Fully digital minimal-deviation filter.
- Practical sector-power/leakage-budget reference implementation.
- UMa-based cellular baseline and harmonized model roles.
- Clean regulatory/configuration YAML with status labels.
- P.530-19 wanted-link equations and an executable S1 gate.
- Demo E1, E2, and E3 runners.
- Sionna/WMMSE interchange contract.
- Completion and paper-readiness checklists.

## Not completed

- Real paired GTA fixed-link input for S1.
- Reviewed incremental-outage allocation.
- Final decision on the provisional +19 dB candidate.
- Validated P.452-18/P.2108 coupling matrices.
- Real nominal beamformer export from Sionna/WMMSE.
- Real or high-fidelity residual dataset for uncertainty calibration.
- Runtime/scalability campaign.
- Final E1-E3 statistics and paper figures.
- Results-complete JSAC/TWC manuscript.

## Go/no-go decision

**GO. Do not restart.** The next value comes from execution and validation, not from adding more conceptual material.
