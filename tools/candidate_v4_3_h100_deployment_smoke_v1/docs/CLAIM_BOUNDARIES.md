# Claim boundaries

A successful run supports only this statement:

> Candidate v4.3 reproduces the excluded seed-43999 floor/EESS pass in the Rorqual H100 deployment environment while reusing the immutable channel and preserving the strict post-mode power and bounded local action-scope gates.

It does not establish:

- confirmatory multi-seed performance;
- calibration to a deployed network;
- regulatory compliance;
- distributed information-exchange sufficiency or measured latency;
- hardware PA/EVM feasibility;
- statistical superiority suitable for the final paper.

The H100 validates environment and preserved-channel integration. The controller optimization remains the CPU NumPy/SciPy/HiGHS implementation used by the phase-1 RRM path.
