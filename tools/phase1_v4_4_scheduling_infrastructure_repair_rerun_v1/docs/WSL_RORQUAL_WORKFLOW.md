# WSL/Rorqual workflow

The WSL wrapper verifies the release, activates the repository virtual
environment, runs all local gates, stages the versioned infrastructure repair
without overwriting prior evidence, and submits a CPU-only Rorqual array on the
eleven preserved channels.

Measured bounds:

- worker: 8 CPUs, 8 GiB, 6 minutes;
- merge: 4 CPUs, 4 GiB, 3 minutes.

The original WSL shell is never exited by the outer block.
