# Validated full-topology ingestion and dynamic readiness

Run only:

```bash
bash RUN_FULL_TOPOLOGY_INGEST_DYNAMIC_READINESS_DROPIN.sh
```

The drop-in is local-only. It verifies the full and compact validated ZIPs,
extracts the full controller dataset locally, independently freezes concise
evidence, separates total-band and protected-band utility, quantifies
full-versus-chunked differences, evaluates sector sparsity, performs a
geometry-only delay/slew readiness screen, records a nonutility-aware
nonuniform-action opportunity screen, updates project status, builds a compact
review bundle, and pushes readable evidence to GitHub.

The dynamic screens are explicitly non-paper diagnostics. No practical
predictive/CBF controller is claimed by this stage.
