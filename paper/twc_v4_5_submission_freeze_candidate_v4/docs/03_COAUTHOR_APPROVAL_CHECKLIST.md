# Coauthor Approval Checklist

Please record approval or requested edits for each item.

## Scientific content

- [ ] Title and abstract accurately state the contribution.
- [ ] Feasibility-conditioned floor claim is acceptable.
- [ ] SA.509 multiple-entry proxy and frozen-action single-entry stress are stated clearly.
- [ ] Regulatory-compliance and hardware-calibration disclaimers are adequate.
- [ ] Mathematical propositions and implementation descriptions are acceptable.
- [ ] Baselines, holdout statistics, and limitations are represented fairly.

## Submission metadata

- [ ] Author names, order, affiliations, and email addresses.
- [ ] Corresponding author.
- [ ] Funding and acknowledgments.
- [ ] Conflict-of-interest statement, if required.
- [ ] Data/code availability statement.
- [ ] Cover-letter claims and suggested editors/reviewers.
- [ ] Final title, keywords, and graphical abstract policy.

## Final file freeze

- [ ] 13-page manuscript source approved.
- [ ] PDF visually approved.
- [ ] Bibliography and citations approved.
- [ ] Figures and tables approved.
- [ ] Supplementary/reproducibility package policy approved.
- [ ] Submission freeze authorized.
