# Submission-Freeze Plan

After coauthor approval:

1. Apply only approved editorial/metadata changes.
2. Recompile and verify the source/PDF remains within 13 pages.
3. Check title, abstract, keywords, authors, affiliations, acknowledgments, and funding.
4. Run the package audit, citation/reference scan, PDF preflight, and visual inspection.
5. Create one immutable submission ZIP containing manuscript source, figures, tables, bibliography, and final PDF.
6. Record SHA-256, Git commit, date, and coauthor approval.
7. Prepare the TWC cover letter and portal metadata.

No new simulation should be run unless a coauthor identifies a specific claim-critical defect.
