# Practical 64T64R architecture mapping and phase-1 review candidate

Run only:

```bash
bash RUN_PRACTICAL_ARCHITECTURE_PHASE1_PREP_DROPIN.sh
```

This local-only stage maps the 128-port upper reference to generic 64T64R and 32T32R subarray models, performs exact one-seed controller/fallback audits, and creates an execution-blocked phase-1 campaign review candidate. It does not model a specific commercial product and does not submit a cluster job.
